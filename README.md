
# Book Rental Management System

An individual university project developed for a Database Systems course. The project focuses on relational database design and SQL implementation for a book rental management system.

## Project Overview

The database supports a book rental system, including book catalog management, member accounts, and book loans. It uses relational database concepts and SQL features to manage data and implement business logic.

## Database Features

- Relational database schema and relationships
- Tables, constraints, and sample data
- SQL queries for retrieving and analyzing data
- Advanced SQL features, including views, functions, and stored procedures
- Triggers to support database operations and maintain data consistency
- Book loan and return processes
- Overdue loan and fine-related logic

## Technologies

- SQL
- MySQL / MariaDB
- DBeaver
